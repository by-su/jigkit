`library/skills/<id>/` 의 최소 형태다. 등록된 오픈소스 소스가 아니라 **이 저장소가
직접 갖는 로컬 스킬**이고, 프로필은 네임스페이스 없이 `skills: [example]` 로 참조한다.

`SKILL.md` 옆에 `scripts/`·`references/`·`templates/` 를 두면 통째로 따라온다.
기동 시 읽히는 것은 위 `description` 한 줄뿐이라 부속 파일은 세션 비용이 0이다.
